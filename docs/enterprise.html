05 ENTERPRISE & CLOUD

OSS stays AUTH_REQUIRED=false CLOUD=false (anon editor, filesystem). Flip env to get enterprise without code change.

OSS DEFAULTS (FREEMIUM)

  • AUTH_REQUIRED=false · no login
  • CLOUD=false · storage/ on disk
  • STORAGE_BACKEND=fs
  • Tests run with no DB/Redis — ls -R fallback

FLIP TO ENTERPRISE

  • AUTH_REQUIRED=true → JWT + API-key + RBAC
  • REDIS_URL=redis://… → cache 60s + queue 202
  • DATABASE_URL=postgres://… → PG + pg_trgm
  • USE_POLARS=true · STORAGE_BACKEND=s3

CLOUD = MULTI-WORKSPACE

CLOUD=true → storage/workspaces/{ws_id}/datasets/{id}/, per-workspace LLM keys, Stripe mock, white-label, row-level isolation. See docs/CLOUD.md + docs/enterprise.md

CLOUD=true
STRIPE_SECRET_KEY=sk_test_…
WORKSPACE_ID=ws_123  # per request header X-Workspace-Id

WHEN TO USE WHAT

LOCAL / OSS
docker compose up — no DB, no keys
TEAM
AUTH + PG + Redis + S3
SAAS
CLOUD + workspaces + Stripe
