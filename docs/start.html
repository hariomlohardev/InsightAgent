01 START

Get talking to your CSV in 30 seconds. No keys needed — heuristic handles 15+ queries. Add GROQ_API_KEY for smarter.

QUICK START — DOCKER (RECOMMENDED)

cp .env.example .env   # add LLM key (optional)
docker compose up --build
# Backend http://localhost:8000/docs
# Frontend http://localhost:8501
WITHOUT DOCKER
cd backend && pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# new shell
cd frontend && pip install -r requirements.txt
streamlit run streamlit_app.py --server.port 8501
TRY THESE PROMPTS
  • “Show top 5 products by sales”
  • “Sales by Region — bar”
  • “Why did sales drop in March?”
  • SELECT Region, SUM(Sales) FROM df GROUP BY Region

ENV & LLM — AUTO PICKS FIRST KEY

Heuristic stays active with no key. Set any key, LLM_PROVIDER=auto picks first available.

OPENAI_API_KEY → gpt-4o-mini
GROQ_API_KEY=gsk_… → llama-3.1-8b (free, fast)
GOOGLE_API_KEY → gemini-1.5-flash
ANTHROPIC_API_KEY → claude-3-5-sonnet
OLLAMA_URL=http://localhost:11434 → llama3.1:8b (local)

Check GET /api/llm/info and GET /health → llm.provider. Tests run with no key.

FIRST CHART

  1. Upload sales.csv (or Excel) in sidebar.
  2. Ask “Show top 5 products by sales” — get bar chart + table.
  3. Pin to dashboard, try forecast / outliers / what-if.

STORAGE — NO DB REQUIRED

storage/datasets/{id}/data.csv (+ data.parquet when >100k) + meta.json. Filesystem fallback keeps docker compose up working. Optional DATABASE_URL + REDIS_URL upgrade to PG/Redis.
