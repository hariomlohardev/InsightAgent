03 API

Interactive docs at /docs (Swagger) + /redoc. Base http://localhost:8000.

X-Cache / X-Concurrency headersJSON · multipart

ENDPOINTS

GET /health → status + llm.provider
GET / — root ping
POST /api/datasets/upload (multipart csv/xlsx)
GET /api/datasets?q=& limit= — search ilike / pg_trgm
GET /api/datasets/{id} — profile + preview — X-Cache
POST /api/chat — {id, question, sql?} — X-Cache:HIT 3.5ms
POST /api/dashboards/{id}/widgets — pin
GET /api/dashboards?share=slug — public
POST /api/connectors/{id}/query — read-only
POST /api/datasets/join — DuckDB join 2–3
POST /api/schedules — APScheduler cron → email/Slack
GET /api/llm/info — provider/model

Full table: ARCHITECTURE.md#API

CURL CHEATSHEET

curl -F "file=@sales.csv" http://localhost:8000/api/datasets/upload
curl http://localhost:8000/api/datasets/{id} -i | grep X-Cache
curl -X POST http://localhost:8000/api/chat -H "Content-Type: application/json" \
  -d '{"dataset_id":"{id}","question":"Show top 5 products by sales"}' -i | grep X-Cache
curl http://localhost:8000/api/llm/info | jq

HEADERS TO WATCH

  • X-Cache: HIT / MISS — 60s TTL, key chat:{id}:{qhash}:{version}
  • X-Concurrency: Semaphore(20) — 429 when saturated
