2. ENV & LLM

Heuristic covers 15+ queries with no key. Set any key, LLM_PROVIDER=auto picks first:

  • OPENAI_API_KEY → gpt-4o-mini
  • GROQ_API_KEY=gsk_… → llama-3.1-8b (free)
  • GOOGLE_API_KEY → gemini-1.5-flash
  • ANTHROPIC_API_KEY → claude-3-5-sonnet
  • OLLAMA_URL=http://localhost:11434 → llama3.1:8b

Check GET /api/llm/info and GET /health.

5. BLAZING (BF-01…BF-06)

plan/blazfast/ (7 docs) + BENCHMARKS.json is source of truth.

  • BF-01 Measure — bench_profile --json --per-col + bench_read + DEBUG_PROFILE
  • BF-02 Hot Path — vectorized isna/nunique, skip value_counts if >1000, scan→streaming 1M 1.79s→1.38s -23%
  • BF-03 Cache — chat:{id}:{qhash}:{version} → X-Cache:HIT 3.5ms (p95 111ms)
  • BF-04 Storage — to_parquet if >100k (200k 48ms vs 205ms)
  • BF-05 Frontend — @st.cache_data + describe 8 keys -33% + 20/page
  • BF-06 Scale — Semaphore(20) + X-Concurrency p95 <150ms

Reproduce: PYTHONPATH=backend python scripts/bench_profile.py --rows 100000 --json --per-col

6. ENTERPRISE & CLOUD

OSS stays AUTH_REQUIRED=false CLOUD=false (anon editor). Flip: AUTH_REQUIRED=true → JWT/API-key, REDIS_URL → cache(60s)/queue(202), USE_POLARS=true, STORAGE_BACKEND=s3. Cloud CLOUD=true → storage/workspaces/{ws_id}/, Stripe mock, white-label. See docs/enterprise.md + docs/CLOUD.md.

7. CONTRIBUTE

make format && make lint && make test before PR. CI runs lint + backend (3.10/11/12 + PG/Redis) + bench 100k + frontend AppTest + docker config → required gate. Welcome bot + auto-label → one review → merge. See CONTRIBUTING.md.
