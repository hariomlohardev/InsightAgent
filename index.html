What it does

📊 Chat → charts

Planner → Coder (14 templates, no import) → Executor (AST-secured, 5s) → Explainer. Plotly line/bar/pie/scatter/heatmap/hist.

🔌 Live connectors

Postgres/MySQL/SQLite/BigQuery/Sheets + DuckDB join on 2–3 datasets.

📈 Analytics

why / outliers / segment / forecast / what-if / correlation.

🧹 Wrangling

Preview → apply → undo (versioned, diff).

📌 Dashboards

Pin grid, ?share=slug public, export JSON/CSV/PDF.

⏰ Automation

APScheduler cron → Email/Slack PDF, Slack /insight, comments, reports.

1. Start

cp .env.example .env   # add LLM key (optional)
docker compose up --build
# Backend http://localhost:8000/docs  Frontend http://localhost:8501
# Local: cd backend && pip install -r requirements.txt && uvicorn app.main:app --reload
#        cd frontend && pip install -r requirements.txt && streamlit run streamlit_app.py

Storage is storage/datasets/{id}/data.csv (+ data.parquet when >100k) + meta.json. No DB/Redis required — filesystem fallback keeps docker compose up working.

2. Env & LLM

Heuristic covers 15+ queries with no key. Set any key, LLM_PROVIDER=auto picks first:

  • OPENAI_API_KEY → gpt-4o-mini
  • GROQ_API_KEY=gsk_... → llama-3.1-8b-instant (free, fast)
  • GOOGLE_API_KEY → gemini-1.5-flash
  • ANTHROPIC_API_KEY → claude-3-5-sonnet
  • OLLAMA_URL=http://localhost:11434 → llama3.1:8b

Check GET /api/llm/info and GET /health → llm.provider. Tests run with no key.

See ARCHITECTURE.md and plans/00_ROADMAP.md (L1→L12). Security: AST validate_code blocks os,subprocess,... + __import__, 5s timeout.

4. API

Docs at /docs. Key: POST /api/datasets/upload · GET /api/datasets/{id} (X-Cache) · POST /api/chat (X-Cache:HIT <5ms) · POST /api/dashboards/{id}/widgets · POST /api/connectors/{id}/query (read-only) · POST /api/datasets/join · POST /api/schedules · GET /health. Full table in ARCHITECTURE.md#API.

5. Blazing (BF-01…BF-06)

plan/blazfast/ (7 docs) + BENCHMARKS.json (machine) is source of truth.

  • BF-01 Measure — bench_profile --json --per-col + bench_read + DEBUG_PROFILE
  • BF-02 Hot Path — vectorized isna/nunique once, skip value_counts if unique>1000, skip dup if >1M, scan_parquet→streaming (1M 1.79s→1.38s -23%)
  • BF-03 Cache — chat:{id}:{qhash}:{version} → X-Cache:HIT 3.5ms (20 concurrent p95 111ms)
  • BF-04 Storage — to_parquet if >100k (200k 48ms vs 205ms)
  • BF-05 Frontend — @st.cache_data + describe 8 keys -33% + 20/page
  • BF-06 Scale — Semaphore(20) + X-Concurrency (p95 <150ms)

Reproduce: PYTHONPATH=backend python scripts/bench_profile.py --rows 100000 --json --per-col — CI bench job asserts <1s and streaming < scan.

6. Enterprise & Cloud

OSS stays AUTH_REQUIRED=false CLOUD=false (anon editor). Flip: AUTH_REQUIRED=true → JWT/API-key, REDIS_URL → cache(60s)/queue(202), USE_POLARS=true, STORAGE_BACKEND=s3. Cloud CLOUD=true → storage/workspaces/{ws_id}/, Stripe mock, white-label, per-workspace LLM. See docs/enterprise.md + docs/CLOUD.md.

7. Contribute

make format && make lint && make test before PR. CI runs lint + backend (3.10/11/12 + PG/Redis) + bench 100k + frontend AppTest + docker config → required gate. Welcome bot + auto-label + auto-assign hariomlohardev → one review → merge. See CONTRIBUTING.md.
